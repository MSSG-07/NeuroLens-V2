## 📓 Notebooks

This repository contains two versions of the NeuroLens V2 notebook:

| Notebook | Purpose |
|---|---|
| `NeuroLens_V2_3D_to_2D_Generalization.ipynb` | Original notebook containing the executed experiments, outputs, visualizations, and results. |
| `NeuroLens_V2_3D_to_2D_Generalization_Placeholder_Paths.ipynb` | Reproducibility version with configurable placeholder paths, allowing others to connect their own datasets and run the experiments. |

**Why two versions?** The executed-results version documents the actual experimental work, while the placeholder-paths version makes the research pipeline easier for others to reproduce in their own environments.
