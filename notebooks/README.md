## 📓 Notebooks

This repository includes two complementary Jupyter notebooks:

| Notebook | Purpose |
|---|---|
| `NeuroLens_V2_3D_to_2D_Generalization_Placeholder_Paths.ipynb` | The main NeuroLens V2 research notebook. Contains the complete experimental pipeline for 3D teacher training, 2D student distillation, evaluation, and hypothesis validation. Dataset and output paths are replaced with configurable placeholders so users can connect their own data. |
| `NeuroLens_V2_Setup_Template.ipynb` | A general setup template for users who want to configure their own environment, dataset directories, and workspace before running the research pipeline. |

**Why two notebooks?** The first preserves the complete research implementation, while the second provides a reusable starting point for adapting the project to a different environment or dataset. This separation makes the research workflow easier to reproduce without requiring users to modify the original experiment code.
