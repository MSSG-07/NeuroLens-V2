## Research Purpose

Together, these visualizations support the central NeuroLens V2 research objective:

**Can knowledge learned from 3D volumetric MRI data be transferred to a 2D student model that performs classification, segmentation, and spatial depth estimation using isolated MRI slices?**

The figures provide complementary evidence through training behaviour, optimization, classification predictions, segmentation examples, depth estimation, and teacher–student comparison.

## Reproducibility

These figures were generated by the NeuroLens V2 experimental pipeline. Refer to the notebooks and source code in the main repository for the corresponding model configurations, evaluation procedures, and visualization generation steps.

The visualizations represent selected experimental outputs and should be interpreted alongside the corresponding quantitative results. They do not independently establish clinical validity.
